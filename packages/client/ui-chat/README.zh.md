# @deepseek-ai/dsh-client-ui-chat

[English](README.md) | 中文

## 概述

使用本包可在浏览器中渲染已记录的 Session 对话，包括历史图片、本地化操作和滚动位置恢复。紧凑显示会收起已完成轮次的过程行，同时保持最终答案和独立有用的上下文可见；已打包的历史 Assistant 连续消息保持收起。本地 transcript（文本记录）与 steering（中途引导）提交会立即显示并保留在原区域，在权威会话记录到达时原子地消失，而排队中的提交始终不进入 Chat。本包不组装或修改模型请求。

文件提及提供方同时接收当前查看的会话 ID 与收尾轮次的属主信息，因此继承历史中的链接可以指向 fork 自身。

<a id="reference-previews"></a>
## 引用预览

已发送的文件引用及消息日志确认调用的 skill 可在右侧栏打开预览。文件路径使用当前查看的 Session；skill 名称由该 Session 当前的输入触发源解析。两者悬停或聚焦时均使用正文文件链接的虚线下划线。会话、目录和命令标签仍只作为引用展示。

<a id="system-prompt-row"></a>
## 系统提示词行

每个非空追加的 `system/message` 都拥有一行折叠提示词，包括无 header 窗口起点的完整提示词；同一步骤的 header 不会重复它。Chat 也会为非空的初始请求、显式消息序列起点、文本发生变化的 `system/message` surface 节点替换（文本读取自 `request/header` 处 surface 顺序中最后一个非空存活系统节点），或前序 header 尚未进入已加载历史窗口的非初始请求显示一行默认折叠的 `系统提示词`。即使系统文本未变，恢复也会重复该行，包括分页补齐前序 header 和系统节点后；同一序列内仅配置或仅工具变化、工具步骤与重试不会重复，且 `system/message` 事件绝不会渲染为对话消息。该行位于请求的用户消息之前，与提供方 envelope 顺序一致；展开后显示模型所见的确切文本，并保留其原始换行。系统节点为空或位于已加载窗口之外的请求不创建该行，直到包含该节点的分页到达。

<a id="turn-token-usage"></a>
## 轮次 token 用量

只有当已加载窗口包含 `turn/start`，且每次已启动的模型尝试都报告安全、精确的用量时，已完成轮次才显示可展开的用量行。该行会省略不可用的可选用量桶。记账不完整或相互矛盾时，整个详情都不显示，避免把部分总量冒充完整结果。

设置 → 通用设置 → 性能与用量将 `ui-chat.performanceUsage` 保存为 `detailed`（默认）或 `compact`。简洁模式仅在输入框下方显示可用的输出速度和缓存命中率，不显示统计交互卡片或每轮用量。详细模式提供会话统计和每轮 token 用量。两种模式的已完成轮次页脚均不显示耗时。该偏好仅影响展示，记账和 Session 事件保持完整。

在非回环地址浏览器中，设置作用域无法持久化写入，因此该偏好仅在当前进程内生效。明确选择会立即更新所有使用方；回环地址浏览器收到 Host 已接受的设置后会同步当前值。

<a id="completed-turn-footer"></a>
## 已完成轮次的页脚

已完成轮次的操作页脚固定在本轮底部，距前方正文或扩展内容 20px。仅最后一轮以回复正文结尾时常显按钮；末尾为推理、工具、提示或其他内容时，与历史轮次一样通过悬停或键盘聚焦显示。不支持悬停的设备始终显示按钮。反馈与复制仍针对最后一条文字回复。

<a id="turn-process-folding"></a>
## 轮次过程折叠

每个思考行初始都折叠，包括流式输出期间和仅含思考的回复。点击该行可展开或收起完整 Markdown；后续回答文本、工具调用和流结束都保留用户的选择。展开的思考采用紧凑的次级排版：标题只加粗，不改变字号、行高或颜色。流式生成期间，收起预览仅在某段第一行结束后切换；尚未结束的第一行不会替换当前预览。预览从左侧起始，超出可用宽度的内容在右缘渐隐。结算后，简洁模式只显示「思考」，详细和完全展开模式显示首行预览。

「设置 → 通用设置」提供持久化到 `ui-chat` 命名空间的「工作过程展示」偏好：简洁（默认）、详细、完全展开。三种模式均保留一级整轮折叠，已完成轮次默认收起。详细默认收起步骤组，允许手动切换；完全展开在一级折叠内直接平铺步骤，不显示二级标题、折叠控件或限高的组内滚动区。每个二级标题默认以前置的现有工具图标表示类别，其中命令类别使用 Bash 的 `IconApiOutlineRegular`。悬停或键盘聚焦时，该前置图标原位切换为箭头：收起时朝下，展开时朝上，标题尾部不再显示箭头；悬停可用的整轮或二级折叠标题时，文字颜色加深。收起的二级标题不带垂直内边距，与相邻 Assistant 消息相隔 12px；展开标题与首个过程行相隔 12px，相邻过程行相隔 8px。持久化字段 `transcriptView` 接受旧值 `normal`，客户端将其读取为 `expanded`，不主动改写存储；用户选择后仅保存三个新值。所有工作过程展示模式均不显示系统提示词、普通上下文注入和 permission 命令行。非人工轮次发起提示仍独立显示在一级折叠上方；隐藏的元数据不产生过程组或折叠箭头。简洁与详细模式下，Assistant 回复之间的连续过程行都默认收起，同一节点内正文之前的推理也归入过程组。进行中的标题显示最新运行工具的类别，没有运行工具时显示分析阶段，并在过程组关闭前循环显示文字扫光。每个已显示的进行中标题至少保留 150ms；这段时间内的变化只保留最新标题，不排队补播中间工具。详细模式在类别后用空格追加该工具的命令、搜索词、URL、文件路径或描述，不包含思考正文，完成后不再显示这些细节。重试行独立展示，不归入二级过程组。下一条 Assistant 回复开始输出可见正文时，该组转为完成。完成标题按类别统计不同调用，同一路径的多次调用分别计数，显示调用最多的前三类但不显示数量；次数相同按首次出现顺序排列。两类用「并」（英文为 “and”）连接，仅当两项均以「已」开头时共享首个「已」；三类用逗号连接，超过三类追加「等」（英文为 “etc.”）。英文后续动作短语首字母小写。没有工具统计时，使用分析完成的回退文案。系统提示词、上下文注入与权限元数据不计入类别。二级展开区在 400px 与视口高度的一半之中取较小值作为最大高度；存在隐藏内容的方向显示 24px 渐隐遮罩，到达对应滚动边缘时该侧遮罩消失。到 `turn/end` 时，最后一个步骤只有在包含非空文本、图片或未知可见块且不含工具调用块时才成为最终答案边界；边界之前的推理、较早 Assistant 内容、工具行与重试行随后默认收起。控件在 `turn/start` 时出现，执行期间始终展开且不可点击。标题文案为「深度求索中，用时…」（英文为 `Deep diving for …`），最少显示 1 秒且不带前置图标。运行、完成、停止和失败的整轮状态文案均使用 tertiary 灰度，字号比普通状态小 1px。运行时钟每秒更新，显示整数秒且个位秒不补零，满 60 分钟切换为小时。简洁、详细和完全展开均只使用该整轮控件显示轮次运行状态。正常完成后固定时长，最少显示 1 秒，显示「用时…」（英文为 `Took …`），默认收起。取消后显示「已停止」（英文为 `Stopped`）；失败后显示「处理失败」（英文为 `Failed`）。进行中、取消或失败的轮次始终展开，控件不可点击且不显示箭头。缺少起点时间戳时省略时长。没有过程行或内联推理的轮次保留用时标题，但隐藏箭头并禁用折叠。摘要下方的通栏分隔线将其与正文或展开后的过程行隔开。用户与 steering 消息、错误、最大 token 与 turn-tail 行留在过程组外；关闭时没有最终答案的轮次会收起所有过程行，独立行保持可见。新的过程控件插入时不会改变既有行的相对顺序：开场人工输入从首次投影起便位于控件和过程行之前，系统提示词行不显示。仍可通过「加载更早」获取历史时，已加载 `turn/start` 的已关闭轮次可以独立折叠，包括由上下文注入唤起的轮次。缺少起点的轮次会等待分页补齐起点或加载完历史；其他尚未加载的轮次不会阻止折叠。稳定 Chat Node Seat 保持行的位置，隐藏成员不产生消息流间距；只有中间没有独立输入时，收起控件才与正文相隔 8px。完成后的收起不依赖是否跟随尾部，因此正在上方阅读的用户可能看到 transcript 重排。若自动收起会隐藏当前键盘焦点，则过程组保持展开且焦点留在原处；手动收起会先把焦点移到过程控件，再隐藏成员。收起整轮会把内部过程组和工具详情重置为折叠；隐藏的过程 renderer 重新挂载，seat 保持稳定。会话作用域存储记录完成后的手动展开正文 generation；不同正文 generation 均默认收起。

<a id="scroll-ownership"></a>
## 滚动归属

Chat 会在历史前插与 renderer 重新挂载时恢复语义锚点。没有读者移动的贴底滚动事件会立即更新跟随归属，避免后续布局变化使其底部位置失效。读者移动即使位于跟随阈值内，也保持待处理直到采样周期或 `scrollend`，防止布局增长抵消小幅滚动操作。提交正文输入或 steering 时立即恢复跟随底部，并清除先前待处理的读者滚动采样。读者跟随底部时，`ResizeObserver` 追随新的底部，并且无需读取行几何就选中最后一个已加载轮次；读者离开底部后，高度变化会保持顶部位置，再由阅读线几何选择活跃轮次。轮次导航预览位于 Markdown 代码块粘性头栏上方，而导航外框始终处于 composer 上方的 transcript 区域内。

轮次轨道只挂载可见刻度、预加载范围及键盘焦点刻度的相邻项。固定间距和观察到的视口尺寸决定滚动偏移，不读取 DOM 滚动总高度。初始定位等待正文恢复活跃轮次，以及轨道首次获得可用视口尺寸。ref 控制接口分别支持激活轮次和仅滚动轨道；正文自身仍完整挂载。

指针位于轨道外时，自动跟随在活跃刻度中心处于非渐隐区域内时保持轨道不动，越界后才将其居中。预览随指针移动或焦点切换；刻度在静止指针下滚动不会选中另一个预览。

<details>
<summary>滚动实现——点击展开</summary>

`useChatViewport` 负责识别轮次的 DOM 读取、限制范围后的写入与原生事件。`useChatReading` 负责跟随策略、读者输入采样和语义位置记忆；`useChatNavigation` 负责轮次跳转与历史前插时的位置保持。`useChatScroll` 协调已提交的输入。显式导航把测得的落点交给阅读策略，因此无需通过命中测试重新寻找已知目标。

</details>

<a id="model-experience"></a>
## 模型体验

无，因为本包在浏览器中渲染已记录的对话状态，不注册任何面向模型的内容。

#### KV Cache 影响

无；Chat 呈现不会组装或修改提供方请求。

## 已知限制与暂缓事项

<a id="known-limitations-and-deferred-work"></a>

- **transcript 只反映已加载的 Session 窗口**——只有会话控制器加载前一页事件后，更早的 transcript node 才会出现。轮次导航比窗口更宽：轨道把已加载的轮次与宿主 `turnOutline` 投影合并，每个已开始的轮次都有固定间距刻度（相隔 10px；阶梯高于外框时在框内滚动并以渐变淡出标示可滚方向），激活未加载刻度会先把历史分页拉到该轮次的 `turn/start` seq 再落到它的行上。没有该投影时（未挂载 `dsh-session-turn-outline` 的装配），轨道回退到仅显示已加载轮次。
- **导航预览按卡片尺寸截断**——提示词一行（50 字符）、回复至多三行（120 字符），已加载与未加载 Turn 一致；未加载 Turn 的回复要等该轮落定后才随大纲到达，进行中的轮次在此之前只预览提示词（或仅轮次号）。
