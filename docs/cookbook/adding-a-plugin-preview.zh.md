# 实践指南：为内置插件添加功能配图

[English](adding-a-plugin-preview.md) | 中文

当官方内置插件或实验性插件需要用画面解释效果时，使用本指南。开始前应已有可用的插件包及其导出的包清单。最终结果是插件管理页中的一张可选图片，让用户在启用前理解功能。

## 1. 判断是否需要配图

展示一个具体能力或可辨认的结果，例如带署名的文档、变化后的界面，或简明的操作示意。说明文字已经足够时，不填写 `preview`。不要为了占位而配图，也不要把放大的标志当成功能说明。必要的使用信息应保留在本地化说明或配置界面中。

## 2. 设计配图

以下约定适用于官方配图，供创作和设计评审使用；元数据校验检查资源与文件限制，不检查构图或宽高比。需要偏离设计画布时，连同真实页面效果一起交由产品设计师评审。

| 项目 | 约定 |
|---|---|
| 数量 | 每个插件包显示零张或一张功能图。语言版本是同一张图的替代资源，不是多张轮播内容。不提供图集或轮播。 |
| 设计画布 | 默认使用 640 × 300 的横向画布（32:15）。SVG 设置相同的固有尺寸及 `viewBox="0 0 640 300"`。位图可以按相同比例输出 1× 或 2× 分辨率。 |
| 构图 | 一个主要示例，可选一个局部特写。重要内容距画布边缘约 32 个单位；装饰性的纸张或背景可以出血。 |
| 文字 | 文案简短，在页面实际尺寸下可读。层级清楚，字重克制。不能只靠细小的次要文字解释功能。中英文分别调整排版，不把译文强塞进原来的宽度。 |
| 品牌素材 | 保留官方标志及插件实际生成的素材。功能图可以编排、放大这些素材，但不能重画、改色或改写其文字。 |
| 页面外框 | 边框、圆角和外部间距由页面提供。不要把插件开关、安装按钮或外围管理页面画进示意图。 |
| 主题 | 同时检查浅色与深色页面背景。一份自包含图片用于两种主题；当前元数据不按主题选择图片。 |

示意图和界面插画优先使用自包含 SVG；截图或摄影内容使用优化后的 PNG、JPEG 或 WebP。SVG 文字转为路径，不包含字体、远程图片、脚本、事件处理器、动画、样式表或 `foreignObject`。所有语言版本的原始文件总大小不得超过 1 MiB；这是允许的上限，不是目标大小。

[徽章技能包](../../packages/experimental/badge-skill-bundle/README.zh.md)提供了完整示例：一张文档示意配合徽章特写，分别提供两种语言。其他插件不必沿用它的配色、纸张构图或标题字体。

## 3. 声明并发布图片

在导出的包清单中添加 `preview`，并将每个引用的文件加入 `files`；保留该包已有的导出与发布文件：

```json
{
  "preview": {
    "en": "./preview.svg",
    "zh": "./preview.zh.svg"
  },
  "files": ["preview.svg", "preview.zh.svg"]
}
```

含有依赖语言内容的配图提供中英文版本。映射必须包含 `en` 作为回退，并使用 `zh`、`zh-CN` 这样的语言标识；现有界面语言解析器选择其中一张。不同语言的主题和构图保持可辨认的一致性，同时翻译标题、标注和示例内容。产品名、文件名和官方品牌标志可以保持不变。

与语言无关的图片可以使用 `"preview": "./preview.svg"`。所有路径相对于声明它的清单，解析符号链接后仍须位于清单目录内；不接受 URL 或绝对路径。资源加载约定、通过导出声明资源的替代方式及诊断行为见[插件展示元数据](adding-a-package.zh.md#plugin-display-metadata)。

## 4. 检查插件管理页中的位置

从插件入口打开真实的插件包详情页。[详情渲染组件](../../packages/client/ui-plugin-manager/src/client/PluginManagerPage.tsx)及其[样式](../../packages/client/ui-plugin-manager/src/client/PluginManagerPage.module.css)负责以下规则：

| 项目 | 当前行为 |
|---|---|
| 位置 | 位于包说明下方、包含的组件上方，与说明文字的左边缘对齐。 |
| 间距 | 图片上方 24 px；图片与后续详情区之间 32 px。作者不把这些外部间距画入素材。 |
| 展示尺寸 | 保持固有宽高比，不超出可用内容宽度，图片高度最多 320 px。使用 `object-fit: contain`，不裁切、不拉伸。设计画布不代表固定的屏幕显示宽度。 |
| 外框 | 页面提供语义化边框颜色及大圆角令牌（`--dsw-radius-lg`，当前为 16 px）。 |
| 其他视图 | 列表卡片和组件行继续使用小图标。功能图仅出现在插件包详情页。 |
| 可选与异常状态 | 没有配图就不预留图片区。启用前即可查看。读取或解码失败时，仍可启停与配置插件。 |
| 语言与无障碍 | 切换界面语言时选择相应图片，缺失时回退英文。图片具有根据插件标题生成的本地化无障碍名称。必要指引也保留在图片之外的文字中。 |

## 5. 提交 PR 前验收

1. 在仓库根目录运行 `pnpm run verify-package-meta`、`pnpm run constraints` 和 `pnpm run verify-official-bundle-catalog`。确保每个语言版本都纳入发布，并处理资源诊断。
2. 使用 `pnpm run build && pnpm run build:web` 构建真实应用。分别检查插件启用前后、中英文、桌面与 390 px 窗口、浅色与深色主题下的详情页，确认解码、可读性、裁切情况和配图位置；恢复临时调整的显示设置。
3. 检查没有配图的插件包，并按[测试政策](../testing.zh.md)执行相关元数据和界面回归。配图必须保持可选，失败时不能阻断管理操作。
4. 遵循[官方配图评审](../../.agents/skills/dsh-official-plugin-artwork/SKILL.md)及 [record-browser-gif](../../.agents/skills/record-browser-gif/SKILL.md)。含翻译配图的每种语言都附真实页面 GIF，录制所用代码对应 PR 最终提交。配图描述产出效果时，也展示插件的真实输出。
