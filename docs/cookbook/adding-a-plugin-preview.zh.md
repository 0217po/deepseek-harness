# 实践指南：为内置插件添加功能配图

[English](adding-a-plugin-preview.md) | 中文

本指南适用于随应用分发的可选插件包，包括内置的实验性插件。开始前，插件包应已加入应用安装内容及内置可选包清单。第三方插件和按需目录插件暂不支持配图。最终结果是说明下方的一张可选图片，启用前即可查看。

## 1. 判断是否需要配图

展示一个具体能力或可辨认的结果，例如带署名的文档、变化后的界面或简明的操作示意。说明文字已经足够时，不填写 `preview`。不要为了占位而配图，也不要把放大的标志当成功能说明。必要的使用信息应保留在图片之外的本地化文字或配置界面中。

## 2. 绘制一张固定尺寸 SVG

目前只支持下面的格式。`verify-package-meta` 拒绝其他图片格式、尺寸不符的 SVG 和缺少语言版本的声明。构图和视觉质量仍须在真实页面中评审。

| 项目 | 要求 |
|---|---|
| 数量 | 每个插件包显示零张或一张功能图。中英文 SVG 是同一张图的替代资源，不是图集或轮播内容。 |
| 格式与画布 | 只允许 SVG，根节点必须包含 `width="640" height="300" viewBox="0 0 640 300"`。不支持 PNG/JPEG/WebP 文件、其他尺寸、数组或独立的配图导出。 |
| 语言 | 只要提供配图，就必须同时声明 `en` 和 `zh`。翻译标题、标注和示例内容；保留官方品牌素材及产品名。 |
| 构图 | 一个主要示例，可选一个局部特写。重要内容距画布边缘约 32 个单位；装饰背景或纸张可以出血。 |
| 文字 | 简短，在实际显示尺寸下可读，字重克制。全部文案转为路径；中英文分别调整排版。 |
| 品牌素材 | 保留官方标志及插件实际生成的素材。可以调整比例和位置，不重画、改色或改写其文字。 |
| 外框与主题 | 页面提供外围边框、圆角和间距。示意图不绘制外围管理控件，同时检查浅色与深色背景。 |

SVG 必须自包含：不包含字体、远程资源、脚本、事件处理器、动画、样式表、`text` 或 `foreignObject`。SVG 内部的 `image` 元素可通过 PNG/JPEG/WebP 的 base64 data URL 嵌入未改动的官方位图素材；小图标仍只允许几何路径。这个例外用于保留品牌原图，不代表配图可以使用位图文件。校验检查 data URL 格式，不检查解码后的像素；页面通过 `<img>` 渲染 SVG。两份语言源文件合计不得超过 1 MiB；这是上限，不是目标大小。

[徽章技能包](../../packages/experimental/badge-skill-bundle/README.zh.md)展示文档及徽章特写，[语音输入包](../../packages/experimental/voice-input-bundle/README.zh.md)展示语音转为文字。其他功能不必沿用相同配色、构图或标题字体。

## 3. 声明并发布两份语言文件

在导出的包清单中添加 `preview`，将两份文件加入 `files`，并保留该包已有的导出与发布条目：

```json
{
  "preview": {
    "en": "./preview.svg",
    "zh": "./preview.zh.svg"
  },
  "files": ["preview.svg", "preview.zh.svg"]
}
```

使用 `en` 和 `zh` 两个语言键。单一路径、缺少语言、额外语言或文件数组均会被拒绝。路径相对于声明它的清单，解析符号链接后仍须位于清单目录内；不接受 URL 或绝对路径。两份文件都必须纳入发布。清单导出与诊断规则见[插件展示元数据](adding-a-package.zh.md#plugin-display-metadata)。

## 4. 检查真实详情页

从插件入口打开内置插件包详情。[详情组件](../../packages/client/ui-plugin-manager/src/client/PluginManagerPage.tsx)及其[样式](../../packages/client/ui-plugin-manager/src/client/PluginManagerPage.module.css)提供以下规则：

| 项目 | 页面行为 |
|---|---|
| 位置 | 说明下方、包含的组件上方，与说明文字的左边缘对齐。 |
| 间距 | 图片上方 24 px，后续详情区前 32 px。这些外部间距不画入 SVG。 |
| 显示 | 保持 640:300 比例，适应可用宽度，使用 `object-fit: contain` 且最大高 320 px。不裁切、不拉伸；窄窗口缩放固定尺寸的源画布。 |
| 外框 | 语义化边框颜色和大圆角令牌 `--dsw-radius-lg`（当前为 16 px）。 |
| 加载 | 仅在查看由应用安装提供的可选包详情时，通过资源通道读取配图。列表、组件行和设置清单不携带配图数据。 |
| 可选与失败状态 | 未声明配图就不预留图片区。读取或解码失败不阻断启停和配置。列表卡片与组件行保留小图标。 |
| 语言与无障碍 | 界面语言选择英文或中文 SVG。图片使用根据插件标题生成的本地化无障碍名称；必要指引也保留在图片之外。 |

## 5. 提交 PR 前验收

1. 在仓库根目录运行 `pnpm run verify-package-meta`、`pnpm run constraints` 和 `pnpm run verify-official-bundle-catalog`。修正格式、尺寸、语言键、发布条目及资源诊断。第一个校验会分别检查两份 SVG。
2. 使用 `pnpm run build && pnpm run build:web` 构建真实应用。检查启用前后、中英文、桌面及 390 px 窗口、浅色与深色主题下的详情页。确认解码、位置、比例及可读性，并恢复临时显示设置。
3. 检查没有配图的内置包及第三方包，二者均不显示配图。按[测试政策](../testing.zh.md)执行相关元数据与界面回归；错误或缺失的配图不能阻断管理操作。
4. 遵循[官方配图评审](../../.agents/skills/dsh-official-plugin-artwork/SKILL.md)及 [record-browser-gif](../../.agents/skills/record-browser-gif/SKILL.md)。每种语言都附真实页面 GIF，录制所用代码对应 PR 最终提交。配图描述生成效果时，也展示插件的真实输出。
