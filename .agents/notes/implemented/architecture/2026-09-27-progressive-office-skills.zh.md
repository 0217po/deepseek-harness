# Agent Note: Office 技能渐进加载与普通 shell 执行

Status: implemented

[English](2026-09-27-progressive-office-skills.md) | 中文

## 问题

合并的创作和渲染说明会为普通编辑无关的操作消耗上下文。渲染工具激活增加第二条发现路径和持久状态，而 shell 工具已经负责执行权限及进程管理。缺少渲染器也可能阻止加载原本可用的编辑指南。

## 决策

[技能注册表](../../../../packages/skill/skill/README.zh.md) 保留可选的 `modelCatalogVisibility` 元数据，并保留全部胜出候选项。模型目录在作用域和同名解析后过滤 `unlisted` 条目；具名加载与调用权限保持独立。已加载技能说明可以指向延后加载的技能，无需注册工具或引入激活状态。

[Office 提供者](../../../../packages/skill/skill-office/README.zh.md) 仅展示精简路由。各格式创作以及渲染、重计算、PDF 导出分别作为可具名调用的 unlisted 技能。模型按名称加载；以外观为目标的修改会选择渲染，除非用户明确要求跳过。渲染使用任务工作区内随机命名的私有临时目录，并在检查后删除。技能通过普通 Bash 或 PowerShell 调用 `office-check` 和 `dsoffice`。公共基础组合仅在提供运行时时启用不可变技能、Office 命令插件和通用依赖查询。普通 Web 不提供或下载解释器。Web 预设负责工具展示，minimal 预设仍只保留 shell 工具。

命令插件通过 [shell-env](../../../../packages/shell/shell-env/README.zh.md) 将本地启动器加入每次 shell 调用的 `PATH`。载体负责解释器和资源位置；这些路径不进入技能说明。加载技能和注册命令不准备引擎或创作 payload。独立渲染、PDF 导出和重算只需对应操作技能。这使说明加载独立于已安装运行时的布局，同时 shell 执行保留现有权限和进程管理。

Office 依赖范围允许补丁版本更新；根锁文件记录实际解析的适配器与引擎版本。

## 考虑过的替代方案

**保留专属渲染工具。** 小型类型化 schema 能约束渲染参数，但需要专属执行配置、作用域注册、投影和激活生命周期。CLI 操作技能接受 shell 引用和模型选择参数的成本，以复用现有审批、沙箱、取消及输出机制。

**通过禁止模型调用来隐藏技能。** 这也会阻止路由加载它们。可见性必须只影响发现，不授予或撤销权限。在选择胜出项之前过滤会错误地暴露被覆盖技能。

**按文件扩展名自动注入指南。** 扩展名无法区分文本编辑、重计算、转换和用户要求的视觉检查。模型选路使无关操作不进入上下文，并允许显式直接调用。

## 影响

说明加载追加普通的已记录技能结果；操作完成不会擦除这些结果。历史工具记录仍可读取，恢复会话使用现有声明更新机制，无需修改 Session 格式或 agent loop。重新引入专属渲染器需要新的、独立成立的用户或安全要求。

验证覆盖可见性默认值、作用域覆盖、拒绝及显式调用、无可执行文件路径时的创作、native／PTC 请求、恢复和 fork、常规及 minimal 组合、资源打包、上下文预算和真实模型操作选择。渲染失败时保留可用源文件并停止视觉检查；命令成功本身不能证明图片可用。
